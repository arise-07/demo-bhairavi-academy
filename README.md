# Bhairavi Academy Website

NEET & JEE coaching institute website — Nagercoil, Tamil Nadu.
Built by [Primus Tech Labs](https://www.primustechlabs.in).

## Stack
Plain HTML / CSS / JS — no build step, no framework.
- AOS.js — scroll animations
- Swiper.js — testimonials carousel
- Font Awesome — icons

## Files
```
index.html          Main site
style.css            All styles
script.js            All interactivity
robots.txt           Crawler rules
sitemap.xml           Page list for search engines
site.webmanifest      Add-to-homescreen config
404.html             Custom not-found page
favicon.png / apple-touch-icon.png / og-image.png   (add these — see below)
```

## Before going live
- [ ] Replace `https://bhairaviacademy.com` placeholder domain in `index.html`, `robots.txt`, `sitemap.xml`, `site.webmanifest` with the real domain (find & replace)
- [ ] Add `favicon.png` (512x512), `apple-touch-icon.png` (180x180), and `og-image.png` (1200x630) to the root folder
- [ ] Submit `sitemap.xml` to Google Search Console after launch
